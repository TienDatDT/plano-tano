## UI Architecture

- Use Tailwind CSS for styling
- Use Lucide React for icons
- Use Shadcn UI for components

If something already matches the reference, DO NOT change it.

Only modify:
- layout wrappers
- section order
- grouping

Do NOT modify:
- internal component logic
- API calls
- data structure

## Design System Reference

You must strictly follow the design system defined in `.design-system.json`.
- Do NOT invent styles
- Do NOT use unapproved colors or spacing
- Do NOT change component structure
- Use only components from the design system
